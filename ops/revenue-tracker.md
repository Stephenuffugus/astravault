## Targets (honest)

- **30 days:** any revenue. $1 from a patent licensee counts.
- **60 days:** $500-$5,000 (one patent license OR app launch + 100 paying users)
- **90 days:** $1,000-$10,000 cumulative
- **6 months:** $5,000-$50,000 cumulative
- **12 months:** $20,000-$200,000 cumulative

These are the median-to-good outcomes from the zero-budget roadmap. Don't
mistake them for guarantees.

## Update protocol

When money lands:
1. Add to "By source" table above (update the relevant quarter cell + Total).
2. Note the transaction in the activity log below with date + counterparty + scope.
3. Move corresponding line from "Active opportunities" to closed.
4. Update [partner-pipeline.md](./partner-pipeline.md) status.
5. Tell Claude the new state when next opening a session — Claude will help
   plan reinvestment (typically: highest-priority item from
