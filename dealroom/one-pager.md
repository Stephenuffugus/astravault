# Astra Vault — One-Pager

**Astra Vault** is a sky-scanning, star-collecting, citizen-science astronomy app that turns every minute a user spends looking up into a verified, cryptographically-attested attention event. Phones first, smart glasses second. Pi Network tokenomics.

## The product
Users scan the sky, collect 28 named celestial objects across 5 rarity tiers, learn real astronomy through a 24-lesson academy, submit Bortle light-pollution ratings to citizen science, and when they capture a meteor with their phone or smart glasses, Astra Vault cross-references their observation against the Global Meteor Network and SonotaCo Network — showing the user "your meteor was also captured by 3 GMN stations across 127 miles." The patent-novel moment is **cross-glasses observation merge** — multiple users' voice-triggered captures fused by timestamp + bearing into one reconstructed 3D event.

## What's built
A working Expo React Native + react-native-web app with all 5 tabs live, 5 deep-route screens, live integrations with NASA APOD, ISS tracking, NASA SkyView, CDS Aladin Lite v3 (HiPS surveys), Global Meteor Network, SonotaCo Network, and Launch Library 2. End-to-end working moment capture pipeline saves GNSS-timestamped frames with observer pose + cryptographic attention hash + ATP token award + async multi-network cross-reference. ~10,000 lines of TypeScript across 60+ files. Web export builds clean. Public commit log: github.com/Stephenuffugus/astravault.

## The protocol
Astra Vault sits on top of the **SWS Proof of Attention Protocol** — a SHA-256 hash pipeline that converts verified attention events (gameplay, lessons, captures, citizen-science submissions) into cryptographic proofs portable across every game in the SWS ecosystem. The protocol is patented (Stephen Furpahs, sole inventor, owner via LLC).
